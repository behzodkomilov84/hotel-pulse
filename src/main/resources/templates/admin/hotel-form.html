Exely integratsiyasi
Exely PMS kaliti Tavsiya etiladi

Bronlar, haqiqiy holat (zaselenie/vyselenie), to'lovlar va qarzdorlik keladi. Mehmonxonada Exely PMS (STANDART yoki yuqori obuna) bo'lishi kerak.

Kalit qayerda?
  1. Exely extranet'da chap menyuda Управление отелем → Настройки.
  2. Yuqoridagi Интеграции yorlig'i.
  3. Доступ к Универсальному API Exely PMS bo'limidagi Ключ интеграцииni nusxalab, shu yerga joylashtiring.

⚠️ Bu kalit bilan bron va to'lovlarni o'zgartirish ham mumkin — uni faqat shu formaga kiriting, boshqa joyga yubormang.

Bazada shifrlangan holda saqlanadi va sahifada hech qachon ko'rsatilmaydi.
Exely PMS yo'qmi? Exely Connect orqali ulash faqat bronlar

Faqat bronlar va oldindan to'lovlar keladi — qarzdorlik ko'rinmaydi. PMS kaliti kiritilsa, u ustun turadi.

Mehmonxona bu ma'lumotlarni qayerdan oladi?
  1. Exely extranet'da Property settings → API connections bo'limiga kirib, Create a connection tugmasini bosadi.
  2. Ulanishga nom beradi (masalan, "HotelPulse").
  3. Public APIs yorlig'ida Read Reservation API'ni belgilaydi.
  4. Save → Save and enable access tugmalarini bosadi.
  5. Ochilgan sahifadagi client_id va client_secret'ni sizga yuboradi.

Mehmonxona ID — Exely'dagi raqamli identifikator (bron raqamining o'rtasidagi son ham shu: 20210325-500360-6987835).
