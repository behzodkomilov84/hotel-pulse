Exely интеграцияси
Exely PMS калити Тавсия этилади

Бронлар, ҳақиқий ҳолат (заселение/выселение), тўловлар ва қарздорлик келади. Меҳмонхонада Exely PMS (STANDART ёки юқори обуна) бўлиши керак.

Калит қаерда?
  1. Exely эхтранетъда чап менюда Управление отелем → Настройки.
  2. Юқоридаги Интеграции ёрлиғи.
  3. Доступ к Универсальному API Exely PMS бўлимидаги Ключ интеграциини нусхалаб, шу ерга жойлаштиринг.

⚠️ Бу калит билан брон ва тўловларни ўзгартириш ҳам мумкин — уни фақат шу формага киритинг, бошқа жойга юборманг.

Базада шифрланган ҳолда сақланади ва саҳифада ҳеч қачон кўрсатилмайди.
Exely PMS йўқми? Exely Connect орқали улаш фақат бронлар

Фақат бронлар ва олдиндан тўловлар келади — қарздорлик кўринмайди. PMS калити киритилса, у устун туради.

Меҳмонхона бу маълумотларни қаердан олади?
  1. Exely extranet'да Property settings → API connections бўлимига кириб, Create a connection тугмасини босади.
  2. Уланишга ном беради (масалан, "HotelPulse").
  3. Публик APIs ёрлиғида Read Reservation API'ни белгилайди.
  4. Save → Save and enable access тугмаларини босади.
  5. Очилган саҳифадаги клиент_ид ва клиент_секрет'ни сизга юборади.

Меҳмонхона ID — Exely'даги рақамли идентификатор (брон рақамининг ўртасидаги сон ҳам шу: 20210325-500360-6987835).
