Exely

Меҳмонхона Exely PMS ёки Exely booking engine ишлатса — қуйидаги усуллардан бири билан уланг.

Exely PMS калити Уланган Тавсия этилади

Бронлар, ҳақиқий ҳолат (заселение/выселение), тўловлар ва қарздорлик келади. Меҳмонхонада Exely PMS (STANDART ёки юқори обуна) бўлиши керак.

Калит қаерда?
  1. Exely экстранетда чап менюда Управление отелем → Настройки.
  2. Юқоридаги Интеграции ёрлиғи.
  3. Доступ к Универсальному API Exely PMS бўлимидаги Ключ интеграциини нусхалаб, шу ерга жойлаштиринг.

⚠️ Бу калит билан брон ва тўловларни ўзгартириш ҳам мумкин — уни фақат шу формага киритинг, бошқа жойга юборманг.

Базада шифрланган ҳолда сақланади ва саҳифада ҳеч қачон кўрсатилмайди.
Exely PMS йўқми? Exely Connect орқали улаш Сақланган фақат бронлар

Фақат бронлар ва олдиндан тўловлар келади — қарздорлик кўринмайди. PMS калити киритилса, у устун туради.

Меҳмонхона бу маълумотларни қаердан олади?
  1. Exely экстранетда Property settings → API connections бўлимига кириб, Create a connection тугмасини босади.
  2. Уланишга ном беради (масалан, "HotelPulse").
  3. Публик APIs ёрлиғида Read Reservation API'ни белгилайди.
  4. Save → Save and enable access тугмаларини босади.
  5. Очилган саҳифадаги клиент_ид ва клиент_секрет'ни сизга юборади.

Меҳмонхона ID — Exely'даги рақамли идентификатор (брон рақамининг ўртасидаги сон ҳам шу: 20210325-500360-6987835).

Электрон ҳисоб-фактуралар (ЭСФ)

Меҳмонхона my.soliq.uz'да танлаган ЭСФ оператори орқали: кирувчи ҳисоб-фактуралар (етказиб берувчилардан) — USALI харажатларига; чиқувчилар — бронларга (расмий ҳисоб-фактура ёзилган-ёзилмагани). Ҳар куни 03:40 да автоматик янгиланади. Фақат ўқилади — ҳеч нарса имзоланмайди ва юборилмайди.

Синхронланмоқда… Ишлаяпти Хатолик
ЭСФ операторини улаш
Қайси оператор эканини меҳмонхона бухгалтери билади (my.soliq.uz → «ЭДО операторини танлаш»). Кирувчи ҳисоб-фактуралар фақат шу операторда бўлади. Didox учун HotelPulse'нинг ҳамкор токени ҳали созланмаган (Didox билан шартнома) — Didox танланса, текшириш хато беради.
Бу маълумотлар қаердан олинади?
  • ИНН — меҳмонхона (ташкилот) СТИРи, 9 рақам.
  • Didox: фақат ИНН ва Didox пароли (didox.uz'га ИНН + парол билан кириладиган парол; бўлмаса, Didox профилида ўрнатилади).
  • Faktura.uz: Faktura.uz'га кириладиган логин ва парол. Client ID ва Client Secretни Faktura.uz кабинетида ўзингиз яратасиз: Созламалар → «Доступ к API» → «Настройки клиентов» → «Добавить новый»; Client_id — ихтиёрий ном (масалан, hotelpulse), Callback URL — https://hotel-pulse.uz. Сақлангач, Client Secret кўрсатилади — шуни бу ерга киритинг.

⚠️ ЭЦП калити (.pfx файли) ва унинг пароли керак эмас — уларни ҳеч кимга берманг.

Парол ва Client Secret базада шифрланган ҳолда сақланади ва саҳифада ҳеч қачон кўрсатилмайди.
