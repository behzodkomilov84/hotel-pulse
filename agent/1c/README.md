# 1C — HotelPulse интеграцияси (1C:Бухгалтерия, 1C:Отель)

## 1-қадам: базанинг тузилишини аниқлаш (`discover.ps1`)

Скрипт ҳар қандай 1C базасида ишлайди (1C:Бухгалтерия, 1C:Отель ва бошқалар). У базага уланади ва ҳужжатлар,
маълумотномалар, регистрлар (ҳисоб регистрлари билан), ҳисоблар режаси (ҳисоб кодлари ва номлари),
ташкилотлар, бўлимлар ва харажат моддалари номларини `1c-discovery.json` файлига ёзади. **Фақат ўқийди**, 1C'да ҳеч нарса ўзгармайди. Шахсий маълумот (меҳмон исми,
телефон, ҳужжат) олинмайди. Логин ва парол фақат шу компьютерда ишлатилади.

### Тайёргарлик (бир марта)

1. 1C ўрнатилган компьютерда (меҳмонхона сервери ёки 1C:Отель очиладиган компьютер) ишлатинг.
2. COM-коннекторни рўйхатдан ўтказинг — **администратор** сифатида буйруқ қаторида:
   ```
   regsvr32 "C:\Program Files\1cv8\8.3.XX.XXXX\bin\comcntr.dll"
   ```
   (`8.3.XX.XXXX` — ўрнатилган 1C версияси папкаси.)
   1C 32-битли бўлса — `C:\Program Files (x86)\1cv8\...` ва 32-битли PowerShell:
   `C:\Windows\SysWOW64\WindowsPowerShell\v1.0\powershell.exe`.
3. 1C фойдаланувчисида «Внешнее соединение» ҳуқуқи бўлсин (одатда «Полные права»да бор).

### Ишга тушириш

`discover.ps1` ни компьютерга кўчиринг, шу папкада PowerShell очинг:

Файл база (папка):
```
powershell -ExecutionPolicy Bypass -File discover.ps1 -File "C:\1C\Otel" -User "Admin"
```

Сервер база:
```
powershell -ExecutionPolicy Bypass -File discover.ps1 -Server "srv1c" -Base "otel" -User "Admin"
```

Параметрларсиз ишга туширилса — ҳаммасини ўзи сўрайди. Парол яширин киритилади.

Натижа — `1c-discovery.json`. Уни HotelPulse дастурчисига юборинг.
